# 💰 Sistema Contable - Prueba Técnica

¡Hola! Este es el repositorio para mi prueba técnica. Es un sistema contable básico construido con Next.js donde se pueden registrar movimientos de dinero (ingresos y egresos), gestionar usuarios y generar reportes. 

Todo el sistema está protegido por autenticación y un control de roles (ADMIN y USER).

🚀 **[Ver el proyecto en vivo aquí](https://mi-proyecto-contable-eight.vercel.app)**

---

## 🛠️ Tecnologías que usé

* **Frontend:** Next.js (Pages Router), React, Tailwind CSS y componentes de Shadcn UI.
* **Backend:** Next.js API Routes.
* **Base de Datos:** PostgreSQL (usando Supabase) y Prisma ORM.
* **Autenticación:** Better Auth (Inicio de sesión con GitHub).
* **Testing:** Jest (Pruebas unitarias de la lógica de negocio).
* **Documentación:** Swagger UI.
